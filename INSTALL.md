# Quick Installation Guide

## Step 1: Download the Extension
1. Download all the files from this repository
2. Extract them to a folder on your computer (e.g., `call-recorder-extension`)

## Step 2: Load in Chrome
1. Open Chrome browser
2. Go to `chrome://extensions/`
3. Turn on "Developer mode" (toggle in top right)
4. Click "Load unpacked"
5. Select the folder containing the extension files
6. The extension should now appear in your extensions list

## Step 3: Pin the Extension
1. Click the puzzle piece icon in Chrome's toolbar
2. Find "Call Recorder" and click the pin icon
3. The microphone icon should now be visible in your toolbar

## Step 4: Test the Extension
1. Go to any website with audio (e.g., YouTube)
2. Click the Call Recorder icon
3. Click "Start Recording"
4. Grant microphone permissions when prompted
5. Click "Stop Recording" after a few seconds
6. Click "Download MP3" to save the file

## Troubleshooting
- If you see "Could not start recording", make sure you've granted microphone permissions
- If tab audio isn't captured, this is normal for some websites - the extension will use microphone only
- Make sure you're using Chrome (not Firefox or Safari)

## Legal Notice
Always ensure you have permission to record conversations. Check your local laws regarding audio recording.
